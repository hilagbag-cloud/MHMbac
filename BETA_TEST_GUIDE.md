# Guide du bêta-testeur — BacPilot

Bienvenue dans la phase bêta de **BacPilot — par MHM SOLUTIONS**.

## Ta mission

Teste BacPilot comme un véritable utilisateur : recherche de filières et d’universités, profils et mentions, statistiques, classements, recommandations et parcours de personnalisation. Essaie volontairement de trouver les incohérences, erreurs de contenu, problèmes d’affichage et parcours difficiles à comprendre.

Le principe est simple : **teste, trouve, signale, améliore**.

## Outils disponibles dans l’espace bêta

| Outil | Utilité |
|---|---|
| **Badge “Bêta-testeur actif”** | Identifier clairement un compte enrôlé dans la phase bêta. |
| **Bouton “Signaler sur cette zone”** | Depuis le tableau de bord, ouvrir le formulaire directement sur la zone `dashboard`. |
| **Formulaire par catégorie** | Signaler un bug, une incompréhension, une idée ou un point positif. |
| **Zone testée** | Rattacher le retour à l’accueil, l’onboarding, le dashboard, le profil, l’extension, l’authentification ou une autre zone. |
| **Priorité** | Indiquer si le problème est faible, normal, important ou bloquant. |
| **Étapes et résultat attendu** | Donner les informations nécessaires pour reproduire le problème. |
| **Capture privée facultative** | Joindre une image de 5 Mo maximum ; elle reste dans un espace privé lié à ton compte. |
| **Historique personnel** | Revoir les derniers retours envoyés et leur statut de traitement. |
| **Statistiques de test** | Voir le nombre de retours, les bugs ouverts et les actions testées. |

## Comment signaler un problème

Indique ce que tu faisais, ce qui s’est passé, ce qui aurait dû se passer et, si possible, une capture d’écran. Évite de mettre un mot de passe, un jeton, une donnée personnelle sensible ou une information d’un autre utilisateur dans le retour.

## Ton profil bêta

Le statut bêta n’est pas choisi dans le navigateur. Il est attribué côté serveur par l’équipe BacPilot. Une fois le compte enrôlé, l’interface affiche le badge **Bêta-testeur actif**, ajoute l’**Espace bêta** à la navigation et enregistre les événements de test dans un périmètre privé.

Les statistiques servent à mesurer l’usage des fonctionnalités et à prioriser les corrections. Elles ne constituent pas un classement des personnes et ne donnent droit à aucune rémunération.

## Important

La participation est bénévole et peut être arrêtée à tout moment. Les résultats bêta peuvent contenir des erreurs : ne prends pas une décision d’orientation uniquement sur la base de BacPilot. BacPilot propose des pistes ; le candidat vérifie et valide lui-même ses choix sur le portail officiel.
